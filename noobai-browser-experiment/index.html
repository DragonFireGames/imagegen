Memory and storage

NoobAI XL 1.1 is a large SDXL model. Its U-Net weights alone are about 5.14 GB in FP16. The browser loads the text encoders, U-Net and VAE sequentially, releasing each component before loading the next. Start at 768²: this reduces activation memory, not model-weight memory. A 16 GB Mac is a more realistic target, but memory pressure from Chrome, GPU allocations and the U-Net activations can still cause allocation failures.

Persistent storage is requested from the browser. The browser may deny the request or clear best-effort data; the model status reports whether the cache is present.
