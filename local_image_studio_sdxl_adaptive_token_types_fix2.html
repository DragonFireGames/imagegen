Local Image Studio / SDXL Lightning

A separate browser-only SDXL experiment. Generation runs on your device through WebGPU; the model files are fetched from Hugging Face and cached by the browser where possible.

Generation

SDXL-Lightning is distilled for exactly 4 steps and guidance scale 1. Output dimensions should be divisible by 8. Start with 768 × 512.
Ready. The first run downloads roughly 6.9 GB of model data. Keep this tab open and avoid running other GPU-heavy apps.
Memory warning: model files are about 6.9 GB, and peak RAM/GPU memory is higher. On a 16 GB Mac this may still fail depending on the model and other apps. The first load can take a long time.

Model: Cyronius SDXL-Lightning 4-step ONNX. This is a text-to-image prototype; image-to-image and inpainting are not included.
