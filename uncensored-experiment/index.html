True classifier-free guidance

The negative prompt is passed to the model's conditioning branch. It is not used as a prompt filter.

Memory note

Q8 weights are about 4.18 GB; the Q4 low-memory profile is about 2.8 GB. Start at 768² with Q4 if your available memory is limited. Larger images need more runtime memory.
