Implementation sequence

  1. Measure the actual target browser's WebGPU limits and matrix throughput.
  2. Inspect official FLUX.1-dev ONNX graph compatibility and quantized operator support.
  3. Run one real transformer block in Chrome and compare its output with the Colab reference.
  4. Build the full local pipeline only after numerical correctness is established.
