Text-to-image with the WAI Illustrious v17 ONNX pack, both CLIP encoders, classifier-free guidance, the three-part UNet, Euler ancestral sampling, and the VAE decoder. The prompt and generated image stay in this browser; model weights are downloaded from Hugging Face.

Existing implementation reference

      
Browser SDXL · ONNX WebGPU

      
A separate project already runs SDXL in Chrome with a JavaScript pipeline, OPFS caching, FP16 and INT4 UNet variants. Its inpainting example fuses a specific LoRA before export; it does not demonstrate arbitrary live LoRA swapping.

      
We can adapt its SDXL pipeline architecture, then validate the Personal Ami LoRA against Illustrious. This is a reference implementation, not a dependency.
