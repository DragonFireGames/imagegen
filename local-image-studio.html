Experimental standalone build. This page has its own interface and runs inference in the browser; it does not embed another website. To make the first test practical, it currently uses a known-compatible SD 1.5 ONNX checkpoint. It does not download a safety-checker model. The requested Zhare repository's UNet file appears unusually small in its published file listing, so its compatibility needs a separate test before swapping it in.
First load downloads several gigabytes. Use a recent Chrome or Edge build with WebGPU enabled and enough free memory. Model/runtime files are fetched from their upstream hosts; generated prompts and images are not uploaded by this page's inference code.
