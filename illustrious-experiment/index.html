Run 1–4 independent images together; higher values use more GPU memory.

Fast defaults: 512×512 · 12 steps · CFG 1. CFG 1 uses only the positive UNet branch and skips negative-prompt encoding. This trades away negative-prompt control and some guided refinement for speed. For the original guided quality profile, use 28 steps and CFG 5. At the same settings, 1024×1024 requires roughly four times the UNet work of 512×512. Parallel images share prompt conditioning and run through the UNet together; increase Images per GPU pass gradually because GPU memory use grows with the batch.
